# 📊 Amazon Sales Analysis Report

Analyzed Amazon Sales Data by performing data cleaning in Python and creating visualizations using Tableau to extract insights and deliver actionable business recommendations.

---

## 🚀 Key Features

- 📦 **Data Cleaning**: Handled missing values, standardized formats, and cleaned raw Amazon sales data using Python (Pandas, NumPy).
- 📈 **Exploratory Data Analysis**: Identified sales patterns, seasonal trends, and top-selling categories and products.
- 📊 **Interactive Dashboard**: Created in Tableau for dynamic filtering, visual storytelling, and presenting KPIs.
- 💡 **Actionable Insights**: Recommendations provided for optimizing sales strategy, inventory planning, and marketing focus.

---

## 📋 Tools & Technologies Used

- **Python**: Data cleaning and preprocessing (`pandas`, `numpy`, `matplotlib`)
- **Tableau**: Interactive dashboard and visual analysis
- **Jupyter Notebook**: Analysis workflow
- **Microsoft Word**: Final report documentation

---
## 📁 Data Overview

The dataset includes:

- Order Date & ID
- Product Name & Category
- Sales Amount
- Quantity
- Shipping & Profit
- Region & Customer Segment

---

## 📌 Insights & Recommendations

- **Top-Selling Categories** and their contribution to revenue
- **Regional Performance** to identify strong and weak sales zones
- **Profit Margin Analysis** across products
- **Customer Segments** with the highest conversion rates
- Recommendations on **inventory** and **promotion planning**
